# Security Policy

## Reporting a vulnerability

Please report security issues using GitHub's **private vulnerability reporting** — the "Report a vulnerability" button under a repository's **Security** tab — rather than opening a public issue. See [GitHub's guide](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) for details.
